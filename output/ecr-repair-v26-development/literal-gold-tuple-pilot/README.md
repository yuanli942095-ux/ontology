# Literal Gold vs canonical signature pilot

This zero-call development pilot compares normalized exact-string evaluation with a deterministic value signature. Each real semantically equivalent prediction/Gold pair is accompanied by a polarity- or number-changing negative control.

- Exact recall: 2/10
- Canonical-signature recall: 8/10
- Negative false accepts: 0/10
- Criterion: PASS

This is not a replacement for human tuple annotation or an unseen confirmatory set.
